# v0.0.6-alpha

This prerelease simplifies instance diagrams and adds learner progress and
private administrator library and candidate-review tools. Canonical remains the
default; AST feedback, novice Luna explanations, source highlights, all four
behavioral categories, SQLite, the dashboard, and constrained-host JVM reuse
remain available.

- Instance diagrams use a hierarchical layout with labeled connections. Trees,
  shared-child DAGs, cycles, disconnected components, and higher-arity relations
  retain their concrete data; exact tables remain available. Filtering, focus,
  zoom, and trace-state selection remain supported.
- The local-workspace badge appears only in source-checkout loopback previews.
  Public hostnames and IIS packages hide it, including package loopback previews.
- A green exercise check records browser-local progress only after zero edit
  distance and perfect behavioral evidence for the same current draft and
  exercise content. Stale responses cannot award it; changed questions invalidate
  old markers. Draft bodies are not stored in the progress record.
- Administrators can edit public titles/questions and remove exercises. Model
  names, predicate names, environments, facts, and reference bodies remain
  immutable. Removal preserves the original source and upload evidence.
- The private SQLite candidate cache holds at most 100 entries, with at most
  10 per exercise and an 8 KiB predicate-body limit. It is a review queue,
  separate from the approved correct-predicate pool.

## Candidate admission happens before review

A draft enters the cache only when the backend's actual reward equals **1**,
positive and negative samples agree completely, and both undercoverage and
overcoverage searches complete with **UNSAT** and no instances, with model
facts enforced. A rounded `1.000`, a counterexample, a timeout, an unknown or
incomplete result, or malformed evidence cannot admit a draft. Existing known
correct bodies are deduplicated. Capture is optional, bounded, and adds no JVM
launch or AI call to learner editing.

Viewing candidates makes no AI request. An administrator must click **Review
with Sol** to request GPT-6.1 Sol at High effort through the backend's private
key. Advice never publishes a candidate. The administrator retains approval and
dismissal authority; approval independently runs a fresh facts-aware Alloy
equivalence check at scope at least 5 before extending the correct pool used by
both Canonical and AST feedback. The primary behavioral oracle is unchanged.

Admission and approval establish bounded agreement, not an unbounded proof of
equivalence. See the [library/cache specification](../admin-library-candidates-spec.md)
for exact scopes, authority, version checks, retention limits, and failure behavior.

## Validation and proof scope

The local validation records 1,336 distinct Python regressions with latest
outcomes passing, 118 packaged browser checks, seven dashboard checks, and
14 original upload browser checks. The full Python run was followed by a
52-test rerun removing a temporary-directory override and a preview-port
conflict; all prior receipts remain intact. Real Alloy checks cover admission,
malformed and inequivalent
approval rejection, facts-aware equivalence, and newly approved bodies reducing
both hint distances to zero. Provider behavior is tested with mocks; these
records contain no paid review request.

The [diagram audit](../instance-visualization.md#layout-regression-checks) passed
36 focused checks and 2,878 desktop/mobile checks across all 181 invariants,
replaying 1,342 retained instances and 1,439 states without solver or provider
calls. Measured object/text overlap and route obstruction checks passed; exact
returned data was retained.

SQLite uses 16 fixed statements parsed through the pinned
[SQLeanParser](https://github.com/University-of-Wild-Chicken/SQLeanParser) and
bound through the existing parameter kernel. The current-registry source bridge
checks 48 mappings. Two isolated offline Lean 4.34.1 candidate builds audited
83 theorems with empty axiom dependencies and deterministic artifacts. That
candidate is explicitly **BLOCKED** for missing review-ladder checks and does
**not** close a new whole-production formal obligation. Historical proof and
regression evidence remains intact.

## Deployment

Build a fresh timestamped IIS package from this checkout and follow the
[IIS upgrade instructions](../../deploy/iis/README.md). New backend modules,
SQL artifacts, browser assets, and the administrator contract are included.
Private password and OpenAI configuration remain deployment-local and excluded
from archives and public assets. The private IIS ZIP is not a public release
attachment. Local packaging/browser checks do not establish acceptance on an
operator's native Windows/IIS/Cloudflare installation; GitHub's native IIS
workflow reports its own result.

Linux and macOS source-checkout entrypoints remain supported. The project
dashboard reads current GitHub workflow and prerelease metadata rather than
claiming success before those workflows finish.
