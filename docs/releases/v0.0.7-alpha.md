# v0.0.7-alpha

This prerelease fixes full behavioral rewards in the presence of counterexamples,
retains continuously updated private LFU instance pools, and improves the learner
editor and instance labels. Canonical remains the default; AST hints, Luna
guidance, all four instance categories, administrator tools, SQLite, the dashboard,
and reusable constrained-host JVM workers remain available.

- **Counterexample-safe full score.** Integer rounding still displays thousandths,
  but 1.000 requires nonempty, completely agreeing samples and completed,
  facts-aware UNSAT searches for both undercoverage and overcoverage. Every other
  available score is capped at 0.999. Empty pools remain unavailable.
- **Continuously updated LFU pools.** Each behavior JVM retains one exact
  oracle-source/predicate context, with at most 100 private instances per polarity.
  Warm evaluations advance each remaining enumeration, admit current category
  witnesses, and classify the final pools. Mismatches increase usefulness
  frequencies; minimum-frequency eviction uses the oldest admission for ties.
  Context replacement and failed evaluations clear retained state.
- **Fresh behavioral observations.** Completed scores cannot bypass an update.
  Identical pending work still shares one evaluation; workers remain reusable.
  Immutable evidence stays available for explanations of the displayed instances.
- **Readable model environment.** The combined environment uses a TODO predicate
  body and grows to show the full text. Long lines wrap; it has no internal
  scroll area on desktop or mobile. Solver and download bytes remain unchanged.
- **Controlled guidance.** A finite, name-free repair dictionary encodes ordered
  operations. The learner sees the first hint initially and can reveal one more
  at a time, including its Luna explanation.
- **Editor and diagrams.** Alloy keyword coloring, automatic indentation and
  native undo/redo support accompany typed numeric labels and clickable relation
  context. Hierarchical labeled diagrams and exact instance tables are retained.

## Formal contract

The isolated [RWD01 contract](../reward-lfu-contract.md) covers the mathematical
reward gate and finite LFU transitions. Its 92 theorem declarations have empty
transitive axiom dependencies. Two isolated Lean 4.34.1 builds run without a
network interface and compare their inventories and artifacts. Negative controls
reject false full scores, missing witness updates, placeholders and project
axioms. Two Luna, two GPT-6.1 Sol and two Astra reviews bind the frozen inputs.

The [registered verifier](../../scripts/verify_reward_contract.py) and
[proof-block guide](../../formal/reward/README.md) define the finite scope.
Alloy solver correctness, universal Java/Python semantic refinement, allocated
memory, unbounded equivalence and deployment behavior are outside this proof.
Production behavior is tested separately. Historical proof evidence is preserved;
source freshness does not renew older closures after code changes.
The [source-bound RWD01 report](../../closure/reward-contract/evidence/reward-20261008T100725Z-db006f47/report.json)
records VERIFIED for this finite mathematical surface under its declared trust
boundary; it does not establish whole-production formal closure.

## Validation

The broad local Python run exercised 1,377 tests. Four fixture failures were
corrected by including the new runtime and browser modules; a 103-test rerun
passed, including all four failed cases and the changed reward boundaries.
The original failure receipts remain available locally. Synthetic full rewards
are isolated from optional candidate capture; the source exercise database was
restored byte for byte after removing the identified test-only row.

All 500 engine checks, 137 portal browser checks and seven dashboard checks
passed. A fresh diagram replay passed 36 focused checks and 2,878 desktop/mobile
checks across all 181 invariants. Three representative relational/temporal models
completed six cold/warm behavior evaluations with a 256 MiB Java heap and two
configured Java processors, without timeouts; peak measured RSS was 273.5 MiB.
This sample is not a universal latency or memory guarantee. Provider paths use
mocks or are disabled during validation; no paid explanation run is required.

## Deployment

Build a new timestamped IIS ZIP from this version. It includes the LFU/scoring
classes, repair dictionary module, syntax-coloring asset and content-versioned
browser imports. Native IIS acceptance checks full-score and counterexample
behavior, as well as worker-process reuse. Linux/macOS source setup remains
supported. GitHub CI checks the final source on all three operating systems and
performs separate native Windows Server 2022/IIS 10 acceptance.

Deployment password and OpenAI configuration stay private and are excluded from
archives and public assets. The private IIS ZIP is not a GitHub release attachment.
For upgrades follow the [IIS instructions](../../deploy/iis/README.md).
