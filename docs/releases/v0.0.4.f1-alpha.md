# v0.0.4.f1-alpha

This maintenance release closes TRF-01 for the frozen ingress implementation
under its declared trust boundary. It retains persistent JVM reuse, Canonical
as the default, both hint metrics and the complete correct-predicate pools,
including the oracle. Behavioral scores, instance categories and visualizations,
locators, redacted edits, administrator uploads and Luna guidance keep their
existing analysis logic.

Connection reservations now survive the complete handler lifecycle. The reaper
skips its own thread and marks an observation before calling zero-time `join`
and `is_alive`. It clears that mark only after both return normally. If either
call fails, the slot remains occupied until restart: CPython interruption cleanup
can report a still-running handler as stopped, so a later retry is not reliable
evidence of termination. Ordinary successful observations still reclaim finished
threads. The retained exceptional slots remain within the configured limit.

The [constructed before/after witness](../../closure/traffic-refinement/evidence/ting02-observation-interruption/README.md)
reproduces two live handlers under a limit of one with the earlier reaper, and
one with the repair. Earlier startup and teardown counterexamples remain
preserved. Configuration guards reject nonfinite, fractional or unsupported
values before allocating runtime resources and preserve accepted values exactly.

Raw request validation rejects ambiguous separators, HTTP/0.9, missing or
conflicting HTTP/1.1 Host fields, invalid targets and repeated JSON charset
parameters before business dispatch. Header and body deadlines are checked at
completion, including buffered reads and JSON decoding. Public and optional
loopback control listeners have independent admission budgets.
