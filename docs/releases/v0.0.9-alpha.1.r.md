# v0.0.9-alpha.1.r

This release rebases AlloyStudio's Java backend to ACGN
`f955150dec4fc92e35b4ee543a7d71b82381c686` and Alloy 6.2. Canonical stays the
default, with the existing learner workspace, tutor, progress, administration,
behavior examples and bounded warm workers retained.

- AST counting and Zhang–Shasha distance remove transparent `Body` and `NOOP`
  nodes before indexing and matching. The response explicitly identifies the
  new view; these values should not be mixed with older wrapper-counting data.
- Canonical hints project ACGN's selected, replay-checked native edit programs.
  Learner source/canonical locators and structural tutor retrieval use the same
  comparison forms and exact occurrences. Hidden target expressions remain
  excluded from public hints and provider context.
- Runtime delivery includes eight hash-pinned JARs and two parser source
  overlays for the updated Alloy API. The fresh compiler explicitly includes
  the sealed equality-certificate source. All 174 public utility signatures pass
  the Linux parser/identity checks, including the previously blocked sequence
  module; the now-private boolean helper is excluded.
- Behavior and upload validation select the pinned SAT4J factory directly,
  preventing unrelated native-solver probes and leftover temporary files.
- Request-local label/subtree snapshots reduce repeated work without changing
  the frozen cost/alignment digest. Benchmark parsing avoids per-reference
  temporary source files, and a bounded eight-case submission window prevents
  completed responses accumulating in memory. The fresh corpus run preserves
  the paused run and all original baseline archives.
- Source-origin test compilation includes the sealed certificate source, and CI
  identifies class-fixture failures without exposing exception text.
- The compact `graphs.inv7` infographic is regenerated from the production AST
  replay. The fixed historical example pair has 17/13 nodes and distance 8:
  five deletions, two relabelings and one insertion. Its Canonical distance is 5.

The [integration and experiment record](../acgn-rebase-20261109.md) documents
source bindings, resource limits, verification and the full 61,598-case rerun.
Only Canonical and AST are remeasured. TAR and both HiGenA arms retain their
original evidence. Research timing uses four 512 MiB workers and a 60-second
request limit; it does not change the live portal's normal allowance.

Rebuild and restart the backend to load the updated classes. IIS users should
build and deploy a fresh timestamped package, retaining private configuration
and the exercise database. Deployment keys and private IIS archives are not
public release assets. The source checkout remains portable across Linux,
macOS and Windows with Python 3.10+, Java 17+ and Node.js for frontend checks.

This rebase does not renew historical Lean-to-production bindings. Prior proofs,
figures and benchmark reports retain their original hashes and trust boundaries.
