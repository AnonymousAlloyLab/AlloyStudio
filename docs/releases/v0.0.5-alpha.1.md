# v0.0.5-alpha.1

This maintenance prerelease improves GPT-6 Luna's educational guidance.

- Each edit explanation receives the public question displayed above the editor.
  Luna is asked to connect the learner's chosen operator to that requirement,
  explain its possible mismatch, and guide inspection without supplying a repair.
- Zero-distance feedback acknowledges the matching form and encourages another
  solution expressing the same requirement. If the learner uses more code tokens
  than the shortest known correct body, Luna can gently invite a shorter or clearer
  formulation. Comments and spacing are ignored; this is a lexical measure over
  the complete known pool, including the oracle, rather than an AST-node minimum
  or a globally shortest-solution claim.
- The question and numeric comparison participate in exact explanation cache and
  sharing identity. Pinned explanations use retained feedback and existing pool
  data. Code-length evidence adds no parser JVM or solver call.

Both hint metrics, instance explanations, the short summary, source highlights,
administration, SQLite, the dashboard and constrained-machine settings remain.
Canonical is still the default. Private reference bodies, target expressions and
credentials stay outside the provider prompt; approved replacement operators and
learner code retain their existing role. The response schema and stable item IDs
are unchanged.

The [guidance validation report](../ai-guidance-alpha1.md) records bounded
synthetic-provider tests, captured HTTP context, concurrent sharing, credential
portability, and four local Luna qualitative examples. Live Responses API calls
are outside this record. The existing LP05 Java/Lean input root is unchanged;
these prompt changes do not claim a new formal proof of natural-language quality.

Follow the [IIS upgrade instructions](../../deploy/iis/README.md) with the newly
built timestamped package. Per-deployment configuration remains private; the
IIS ZIP is a local deployment artifact, not a public release attachment.
